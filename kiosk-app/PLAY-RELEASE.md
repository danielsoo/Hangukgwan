# Play 스토어 내부 테스트 출시 안내

매장 태블릿 한 대에 Play 스토어를 통해 설치하고, 이후 자동 업데이트까지 받기 위한
절차입니다. 검색에 노출되지 않고, 등록한 계정에서만 설치됩니다.

## 준비된 것 / 직접 하셔야 하는 것

| | 항목 | 상태 |
|---|---|---|
| ✅ | 업로드 파일 `hangukgwan-pos-1.1.aab` | 준비됨 |
| ✅ | 앱 아이콘 512×512 (`play-assets/store-icon-512.png`) | 준비됨 |
| ✅ | 그래픽 이미지 1024×500 (`play-assets/feature-graphic-1024x500.png`) | 준비됨 |
| ✅ | 개인정보처리방침 페이지 (`Qr/app/public/privacy.html`) | 준비됨 (배포 후 URL 사용) |
| ✅ | 스토어 등록정보 문구 / 각종 설문 답변 | 아래 정리 |
| ⬜ | 개발자 계정 등록 ($25) + 신원 확인 | 직접 |
| ⬜ | 스크린샷 2장 이상 | 앱 설치 후 태블릿에서 촬영 |

## 1. 개발자 계정

[play.google.com/console](https://play.google.com/console) 에서 등록. 일회성 미화 25달러.

**계정 유형**: 식당 사업자 명의라면 **조직(단체)** 계정이 맞습니다. 사업자 서류나
D-U-N-S 번호를 요구할 수 있어 개인 계정보다 절차가 조금 깁니다.

> 개인 계정으로도 **내부 테스트**는 문제없이 가능합니다. 다만 나중에 일반 공개 출시로
> 넘어가려면 개인 계정은 "테스터 20명 × 14일 비공개 테스트" 조건을 채워야 합니다.
> 공개 출시 계획이 없다면 개인 계정으로 시작해도 괜찮습니다.

가입 후 2단계 인증을 켜야 하고, Play Console 모바일 앱으로 실제 안드로이드 기기 보유를
확인하는 절차가 있습니다.

## 3. 개인정보처리방침 URL

`Qr/app/public/privacy.html` 이 저장소에 추가돼 있습니다. push해서 배포되면 아래 주소로
접속됩니다.

```
https://(관리자 페이지와 같은 도메인)/privacy.html
```

이 주소를 Play Console → **앱 콘텐츠 → 개인정보처리방침** 에 입력하세요.
문의 이메일이 `yspbusiness605@gmail.com` 으로 들어가 있으니, 다른 주소를 쓰시려면
그 파일에서 바꾸시면 됩니다.

내부 테스트만 할 계획이면 "모든 기능을 특별한 액세스 권한 없이 사용 가능"이 아니라,
로그인이 필요하다고 표시하고 안내문에 *"매장 내부 업무용 앱으로, 등록된 매장 태블릿에서만

## 5. 데이터 보안(Data safety) 답변

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | 예 (아래 한 가지만) |
| 수집 항목 | 개인정보 → **사용자 ID** (매장 관리자 로그인) |
| 목적 | 앱 기능, 계정 관리 |
| 제3자와 공유 | 아니요 |
| 필수 여부 | 필수 |
| 전송 중 암호화 | 예 (HTTPS) |
| 데이터 삭제 요청 가능 | 예 (문의 이메일로 요청) |

> 앱 자체는 광고·분석 도구가 전혀 없고 개인정보를 따로 모으지 않습니다. 위 한 줄은
> "관리자 로그인 정보가 매장 서버로 전송된다"는 사실을 보수적으로 신고한 것입니다.
> 실무상 "데이터를 수집하지 않음"으로 신고하는 경우도 많지만, 위처럼 밝혀두는 쪽이
> 나중에 문제가 될 여지가 없습니다.

## 7. 내부 테스트 트랙에 올리기

1. Play Console → **테스트 → 내부 테스트 → 새 버전 만들기**
2. `hangukgwan-pos-1.1.aab` 업로드
3. **Play 앱 서명** 사용 여부를 물어보면 **사용**으로 두세요 (권장)
   - 우리가 만든 `keystore/hangukgwan.jks` 는 "업로드 키"가 되고, 실제 앱 서명 키는
     Google이 보관합니다. 업로드 키를 잃어버려도 Google에 재설정을 요청할 수 있어
     오히려 안전합니다.
4. **테스터** 탭 → 이메일 목록 만들기 → 매장 태블릿에서 쓰는 Google 계정 추가
5. 저장 → 버전 검토 → 내부 테스트로 출시
6. 목록에 표시되는 **참여 링크(opt-in URL)** 를 태블릿에서 열고 "테스터 되기" → Play
   스토어에서 설치

내부 테스트는 심사가 거의 즉시 끝나지만, 처음 한 번은 몇 시간에서 하루 정도 걸릴 수
있습니다.

## 8. 앱 업데이트할 때

관리자 페이지 내용(메뉴, 화면, 기능)은 앱과 무관하게 지금처럼 push하면 반영됩니다.
앱 자체를 고쳤을 때만 아래가 필요합니다.

```bash
VERSION_CODE=3 VERSION_NAME=1.2 ./build-aab.sh   # 버전 코드는 반드시 올릴 것
```

새 `.aab` 를 내부 테스트에 올리면 태블릿에서 자동으로 업데이트됩니다.

## 9. 사이드로드 버전과의 관계

지금 태블릿에 직접 설치(APK)해서 쓰시다가 나중에 Play 버전으로 넘어가려면, **기존에
설치한 앱을 먼저 삭제해야 합니다.** Play가 앱을 다시 서명하기 때문에 서명이 달라
덮어 설치가 안 됩니다.

앱을 지우면 앱 안에 저장된 설정(관리자 주소, 프린터 IP)도 지워지니, Play 버전 설치 후
설정 화면에서 다시 입력해 주세요. 프린터 IP만 적어두시면 1분이면 됩니다.
