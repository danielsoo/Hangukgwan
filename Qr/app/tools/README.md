# 영수증 숫자 판별기를 다시 굽는 도구

`public/js/receipt-digits.js`(영수증에 손으로 쓴 숫자를 읽는 망)를 **사장님
장부와 사진으로** 다시 만드는 도구들이다. 평소 돌릴 것이 아니다 — 사장님이
사진을 더 주셨을 때, 또는 표 찾기(`receipt-ocr.js`)를 고쳐서 칸이 달라졌을
때만 돌린다.

사진과 장부는 **저장소에 들어가지 않는다**(사장님 영업 기록이다). 자리를
환경변수로 준다:

```bash
export HG_LEDGER=/어디/엑셀이-있는-폴더     # 한국관 식자재 *.xlsx
export HG_PIX=/어디/사진을-꺼낸-폴더        # 영수증 .jpg
```

## 왜 사람이 정답을 안 적는가

사장님 엑셀이 정답표다. 종이에서 센 줄 수가 엑셀 줄 수와 **맞은** 영수증은
「종이 n째 줄 = 엑셀 n째 줄」이므로, 단가·금액 칸의 글자 수가 엑셀 자리 수와
같으면 글자마다 정답이 붙는다. 2026-10-05 에 사진 13,777장에서 그렇게
17,691자를 모았다 — 사람이 한 자도 안 적었다.

## 순서

```bash
# 1. 압축 파일에서 사진을 꺼내고, 엑셀과 짝이 맞는 것만 남긴다
node tools/match.js                 # picked.tsv 를 만든다
#    (압축을 풀고) node tools/keep.js tmpx allpix

# 2. 사진을 브라우저로 읽어 정답을 붙인다 (탭 8개, 13,777장에 5분)
TABS=8 node tools/harvest.js        # big-paired.bin · big-boot.bin

# 3. 망을 여러 가지 재서 고른다
FOLDS=2 EPOCHS=25 NETS=mlp96,cnn8x64,cnn16x96,cnn24x128 node tools/train.js
node tools/baseline.js              # 예전 방식(가까운 이웃)과 견준다

# 4. 고른 것을 public/js/receipt-digits.js 로 굽는다
KIND=cnn16x96 EPOCHS=25 node tools/bake-net.js

# 5. 끝까지 얼마나 되는지 업체마다 잰다
PER=200 node tools/pervendor.js
```

`big-paired` 는 **치우치지 않은** 정답이고(지금 판별기가 뭐라 읽었는지와
상관없이 모인다) `big-boot` 는 지금 판별기가 맞힌 것만 모인 것이다. **시험은
paired 로만** 하고 boot 는 배울 때만 쓴다. 섞어서 재면 잘 되는 것처럼 보인다.

## 어느 파일이 무엇을 하나

| | |
|---|---|
| `truth.js` | 사장님 엑셀을 「가게\|업체\|날짜」로 읽어 둔다 |
| `match.js` | 사진 이름이 장부와 짝이 맞는 것을 고른다 |
| `keep.js` | 짝이 맞는 사진만 남기고 나머지는 버린다 |
| `harvest.js` | 사진을 브라우저로 읽어 **정답 붙은 숫자 그림**을 모은다 |
| `train.js` | 망을 학습시키고 서로 견준다 (손으로 적은 역전파 — 꾸러미를 안 늘린다) |
| `baseline.js` | 예전 방식(가까운 이웃 + k-means 견본)을 같은 자료로 잰다 |
| `bake-net.js` | 가중치를 int8 로 눌러 `receipt-digits.js` 를 쓴다 |
| `split-vendor.js` | 한 업체 것만 뽑는다 |
| `pervendor.js` | 업체마다 끝까지 얼마나 되는지 잰다 |
| `calibrate2.js` | 업체마다 어느 칸이 단가·금액인지 알아내 본다 (**아직 안 된다**) |

## 지금 어디까지 되는가 (2026-10-05)

진짜 사진 1,462장(업체 20곳)으로:

| | |
|---|---|
| 표 찾기 | **73%** |
| 칸 가리기 | **58%** |
| 글자 하나 | **88.5%** |
| 한 줄이 다 맞음 | **22%** (房信菓菜行 40% · 韓濟 34%) |

업체 다섯 곳은 **줄 친 표가 아예 없는 전산 출력 전표**다(千宇開發 · 思皓企業社 ·
瑞騰國際 · 阿寶水産 · 龍江興南北商行). 표 찾기로는 영영 안 되고 글줄을 찾는
다른 길이 필요하다 — 대신 기계로 찍은 숫자라 읽기는 훨씬 쉬울 것이다.
